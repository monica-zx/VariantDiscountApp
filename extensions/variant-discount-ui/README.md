# Variant Discount App

A Shopify app that lets merchants discount cart line items by **variant name**,
using a Shopify Function.

## What it does

From a discount's settings panel in Shopify admin, a merchant can configure:

- **Discount type** — percentage off or a fixed amount off
- **Match mode**
  - `include` (default): only variants whose name matches one in the list get
    the discount
  - `exclude`: every variant gets the discount *except* the ones in the list
- **Variant names** — matched case-insensitively, against either the full
  variant title (e.g. `ABS Plastic / Red`) or any individual option segment
  (e.g. `Red`)

The configuration is stored as a JSON metafield on the discount itself and
read at checkout time by the Shopify Function in
`extensions/variant-percentage-discount`.

### Globo Product Options add-on inheritance

If a cart line is an add-on generated by the
[Globo Product Options](https://apps.shopify.com/product-options-4) app,
it inherits the discount decision made for its anchor line rather than being
matched on its own (usually unrelated) variant name. Globo links an anchor
line and its add-on lines via the `_gpo_product_group` /
`_gpo_parent_product_group` cart line attributes; the function reads those to
group lines before deciding what to discount.

## Project structure

- `app/` — the embedded admin app (React Router), which lists the store's
  existing discounts created with this app
- `extensions/variant-percentage-discount/` — the Shopify Function
  (`cart.lines.discounts.generate.run`) that applies the discount at checkout
- `extensions/variant-discount-ui/` — the discount settings UI shown inside
  Shopify admin's discount editor

## Development

```shell
npm install
npm run dev
```

This uses the Shopify CLI to authenticate, provide environment variables,
create a tunnel, and connect to a development store.

Run the function's test suite:

```shell
cd extensions/variant-percentage-discount
npm test
```

## Deploying

```shell
npm run deploy
```

Note: the Function's discount logic only takes effect on live carts after a
deploy — running `shopify app dev` alone doesn't update the deployed Function
code merchants are using.

## Compliance webhooks

The app implements Shopify's mandatory GDPR webhooks
(`customers/data_request`, `customers/redact`, `shop/redact`). It doesn't
collect or store customer data — the only persisted data is app session
info (`prisma/schema.prisma`), and the discount configuration itself lives in
a metafield on the merchant's own store, not in this app's database.
